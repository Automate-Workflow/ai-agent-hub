# Support

## Getting Help

| Channel | Best for |
|---------|----------|
| [GitHub Discussions](https://github.com/Automate-Workflow/ai-agent-hub/discussions) | Questions, ideas, general discussion, feedback |
| [GitHub Issues](https://github.com/Automate-Workflow/ai-agent-hub/issues) | Data corrections, broken links, bug reports |
| Email: ayush_24a12res897@iitp.ac.in | Private matters, security concerns |

Before opening an issue or discussion, please read:

- [docs/how-to-read-this-hub.md](docs/how-to-read-this-hub.md) — orientation for new visitors
- [CONTRIBUTING.md](CONTRIBUTING.md) — how to contribute corrections or new data

## Response Expectations

Response is on a best-effort basis. This is a volunteer-maintained project with no formal SLA.
Issues and discussions are typically reviewed within 14 days.

## Security Reports

For security-related concerns, do not use public issues. See [SECURITY.md](SECURITY.md) for the
private reporting process.

## Scope of Support

This project supports:

- Questions about using or navigating the knowledge base
- Reporting data errors, outdated information, or broken links
- Proposing new data entries or categories via the issue templates

This project does not provide support for:

- Third-party tools, frameworks, or services listed in the knowledge base
- General questions about AI agents or machine learning not related to this repository
- Custom integrations or private use cases

For questions about the AI agent ecosystem in general, the GitHub Discussions space is a good place
to start a conversation with the community.
