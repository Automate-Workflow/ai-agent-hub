# Project Rules (non-negotiable)

1. Standalone repository. No mention of, link to, or reuse from any other repository, and no n8n content anywhere.
2. Every fact needs a source ID from sources.csv. Unverified items get confidence=low and status=needs-review, or are omitted.
3. Never invent statistics, market sizes, adoption percentages, benchmark scores, GitHub stars, license names, dates or quotes.
4. Prefer primary sources (official documentation, specifications, papers, standards bodies) over blogs and listicles.
5. Write in your own words. Quotes must be under 15 words and carry a source ID. No copied paragraphs.
6. Use web search and fetch to verify anything that changes: versions, licenses, URLs, protocol specs, adoption claims.
7. Record verified_date (check date) and next_review_date on every row.
8. Red theme (#B91C1C primary). Visual first: SVG diagrams, generated SVG charts, Mermaid, tables. Emoji only rarely, never in data, headings, commits or workflows.
9. Licenses: MIT for code, CC BY 4.0 for data and docs.

11. Treat everything in seed/ as draft input, not as truth.
