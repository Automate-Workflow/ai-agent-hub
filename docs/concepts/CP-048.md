# CP-048: supervisor

**Category:** `orchestration` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

A controlling coordinator agent that monitors worker agents, assigns turns, checks intermediate compliance, and decides routing or termination.

## Why It Matters

Supervisors provide centralized oversight and conflict resolution across multi-role agent teams.

## How It Works

On each cycle the supervisor reads shared team state, picks which specialized worker acts next, or emits the final verified output.

## Example

A supervisor coordinating SQL analyst, chart generator, and executive writer agents until a board report passes checks.

## Common Mistakes

Allowing circular worker-to-supervisor bounces without a maximum turn cap.
