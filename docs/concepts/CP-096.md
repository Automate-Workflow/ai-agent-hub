![models](../../assets/icons/models.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

## Definition

Compact language models engineered for low-latency, low-memory, local, or edge execution with competitive narrow-domain performance.

## Why It Matters

Small language models enable privacy-preserving local execution, mobile workflows, and economical high-volume routing.

## How It Works

Compact Transformer architectures leverage curated high-quality data, quantization, and distillation to run cleanly on consumer hardware.

## Example

Running a compact local Ollama model on-device to classify emails offline before invoking cloud services.

## Common Mistakes

Expecting a tiny edge model without tools or retrieval to match frontier multi-domain open reasoning.
