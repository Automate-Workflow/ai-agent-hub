# CP-033: semantic memory

![memory_and_knowledge](../../assets/icons/memory-and-knowledge.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `memory_and_knowledge` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Durable storage of general domain facts, entity profiles, relationships, and world knowledge independent of single timestamped conversations.

## Why It Matters

Semantic memory grounds agents in accurate user preferences, company policies, and structured concepts across sessions.

## How It Works

Extracted facts and entity attributes are organized as triples, documents, or indexed embeddings queried by semantic similarity or key lookup.

## Example

Storing verified product SKU compatibility rules and user accessibility preferences for persistent lookup.

## Common Mistakes

Conflating transient one-off conversation remarks with authoritative enterprise policies.
