# CP-065: zero-shot vs few-shot prompting

**Category:** `foundations` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Guiding model behavior either directly via instructions alone (zero-shot) or paired with curated input-output demonstrations (few-shot).

## Why It Matters

Curated demonstrations resolve edge-case ambiguity and enforce subtle domain formats more reliably than long prose rules.

## How It Works

In-context examples placed in prompts steer token probability distributions toward target tone, taxonomy, and boundary handling.

## Example

Showing five difficult borderline support ticket labels before running production ticket routing.

## Common Mistakes

Including contradictory or unrepresentative examples that skew classification predictions.
