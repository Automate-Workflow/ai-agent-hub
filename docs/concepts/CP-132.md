## Definition

Validating tool payloads statically and dynamically via Python/TypeScript type annotations before invoking external functions.

## Why It Matters

Type-first tooling catches bad model arguments automatically and gives the model structured validation feedback to self-heal.

## How It Works

Frameworks like PydanticAI and Instructor convert Pydantic models into JSON Schemas and return field-level validation errors on failure.

## Example

Returning explicit date-format errors automatically to let the agent retry an invalid search range.

## Common Mistakes

Skipping runtime validation on dynamically produced JSON before forwarding payloads to databases.
