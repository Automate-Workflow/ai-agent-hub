# CP-131: episodic reflection and self-correction

![reasoning](../../assets/icons/reasoning.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `reasoning` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Storing verbal self-critiques from failed episodes and injecting those learned lessons into subsequent attempts on similar tasks.

## Why It Matters

Verbal reinforcement improves task success iteratively without updating underlying neural model weights.

## How It Works

After a test failure or timeout, a critic prompt summarizes the root cause into episodic memory loaded on retry.

## Example

A coding agent remembering previous compiler errors to skip broken dependency paths on run two.

## Common Mistakes

Accumulating redundant verbal notes without pruning superseded heuristics.
