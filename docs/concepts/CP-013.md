# CP-013: intent classification and routing

## Definition

Inspecting an incoming request or intermediate signal and directing it to the most suitable specialist prompt, workflow branch, tool, or model.

## Why It Matters

Accurate routing protects accuracy, keeps prompts focused, and avoids sending routine queries through costly reasoning stacks.

## How It Works

A lightweight classifier, embedding matcher, or LLM router scores request intent and emits a structured route key for downstream dispatch.

## Example

Directing billing disputes to payment workflows while routing technical errors to diagnostics runbooks.

## Common Mistakes

Allowing overlapping route definitions without a fallback handler for ambiguous or multi-intent queries.
