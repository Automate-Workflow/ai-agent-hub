# CP-032: long-term memory

![memory_and_knowledge](../../assets/icons/memory-and-knowledge.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `memory_and_knowledge` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Persistent agent knowledge and experience stored externally across separate sessions and selectively recalled when relevant to future tasks.

## Why It Matters

Cross-session persistence allows assistants, coding tools, and support agents to accumulate project conventions and domain familiarity.

## How It Works

Structured stores, vector indices, or temporal graphs archive semantic facts, episodic events, and procedural instructions outside context windows.

## Example

Remembering repository build commands and formatting standards across engineering sessions weeks apart.

## Common Mistakes

Accumulating stale or conflicting memories indefinitely without timestamps, ownership tags, or retrieval filtering.
