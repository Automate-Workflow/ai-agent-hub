## Definition

Decision modeling that assigns scalar preferences over competing world states so an agent selects actions maximizing expected utility under constraints.

## Why It Matters

Real-world tasks involve competing priorities such as speed, token expense, accuracy, and risk that pure binary goal checks cannot balance.

## How It Works

A utility function weights multiple criteria and evaluates candidate plans or Monte Carlo rollouts to pick the highest-value trajectory.

## Example

A cloud compute scheduler choosing between an expensive fast model and a compact model based on SLA deadline and budget weights.

## Common Mistakes

Optimizing a narrow proxy metric while ignoring safety, latency, or user trust penalties.
