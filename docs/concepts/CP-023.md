# CP-023: tool registry

![tools_and_actions](../../assets/icons/tools-and-actions.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `tools_and_actions` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

A central catalog managing available tool definitions, versioned schemas, metadata, authentication bindings, and access policies for agents.

## Why It Matters

Tool registries let teams govern, discover, and dynamically scope hundreds of enterprise capabilities without hardcoding adapters.

## How It Works

Hosts query registry endpoints or MCP server manifests at runtime to retrieve filtered tool subsets relevant to the active user and task.

## Example

Retrieving only CRM read tools for support triage while withholding billing mutation tools.

## Common Mistakes

Loading an entire organization's unfiltered registry into every agent prompt regardless of user permissions.
