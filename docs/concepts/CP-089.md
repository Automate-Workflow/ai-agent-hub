# CP-089: token cost

![evaluation_and_ops](../../assets/icons/evaluation-and-ops.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `evaluation_and_ops` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Cumulative financial expense of input tokens, cached reads, reasoning tokens, and output completions across an agent execution trace.

## Why It Matters

Multi-turn tool loops re-send growing prompt histories every step, compounding expenses far beyond single-turn chat usage.

## How It Works

Teams track per-trace token consumption, optimize context growth, leverage prompt caching, and route simple steps to cheaper models.

## Example

Cutting support automation unit cost via prefix caching on shared tool schemas and knowledge bases.

## Common Mistakes

Estimating deployment budgets using single-turn chat averages instead of full multi-step loop token totals.
