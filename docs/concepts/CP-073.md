# CP-073: audit log

![safety_and_security](../../assets/icons/safety-and-security.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `safety_and_security` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Tamper-evident chronological records capturing every prompt version, tool call, argument payload, identity, approval decision, and state change.

## Why It Matters

Immutable audit trails enable incident forensics, regulatory compliance, and accountability across autonomous runs.

## How It Works

Hosts emit structured trace and audit events to append-only stores linking run IDs to authenticating identities and tool responses.

## Example

Recording exact user identity, tool arguments, timestamp, and approver ID when issuing a production account change.

## Common Mistakes

Logging only high-level final answers while discarding tool arguments, identity context, and human override events.
