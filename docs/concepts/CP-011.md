## Definition

Algorithmic compilation of prompts, instructions, and few-shot examples against an objective evaluation metric rather than manual trial and error.

## Why It Matters

Metric-driven optimization systematically improves agent accuracy across model upgrades without brittle manual prompt tweaking.

## How It Works

Optimizers such as DSPy bootstrap valid traces, propose instruction variants, score them on validation sets, and select top configurations.

## Example

Compiling a multi-hop QA pipeline against labeled accuracy metrics after switching underlying model families.

## Common Mistakes

Optimizing prompts against unrepresentative synthetic data that overfits narrow wording patterns.
