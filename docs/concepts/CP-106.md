## Definition

An interactive agent combining web browsing automation, DOM or visual page grounding, and planning loops to execute web workflows.

## Why It Matters

Browser agents bridge legacy web portals, SaaS dashboards, and research sites where structured backend APIs do not exist.

## How It Works

The agent inspects simplified page representations or screenshots, chooses clicks/inputs, handles page transitions, and verifies outcomes.

## Example

Using Browser Use to navigate supplier portals, check order backlogs, and export CSV summaries.

## Common Mistakes

Running unguarded web agents over arbitrary internet sites without isolating credentials from indirect prompt injection.
