## Definition

Exploring multiple branching reasoning or action trajectories via Tree of Thoughts or Monte Carlo Tree Search with intermediate state evaluation.

## Why It Matters

Branching search enables backtracking out of dead ends on complex synthesis, planning, and software tasks.

## How It Works

The system samples diverse candidate next steps, evaluates state value via heuristics or critics, and expands highest-scoring branches.

## Example

Exploring alternative refactoring patches in parallel sandbox branches and selecting the branch passing full test suites.

## Common Mistakes

Using expensive tree search on straightforward classification tasks where single-pass inference suffices.
