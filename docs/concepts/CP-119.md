# CP-119: trajectory evaluation

**Category:** `evaluation_and_ops` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Assessing not only an agent's final output, but the exact sequence of intermediate tool calls, arguments, retries, and state transitions.

## Why It Matters

Agents can arrive at lucky right answers via dangerous or broken tool paths unless step trajectories are inspected.

## How It Works

Eval runners log emitted tool trajectories and compare them against expected reference sequences, invariant rules, or latency budgets.

## Example

Verifying a support agent queried policy rules before emitting an approved credit adjustment.

## Common Mistakes

Using overly strict exact sequence ordering checks when equivalent parallel or reordered read calls remain valid.
