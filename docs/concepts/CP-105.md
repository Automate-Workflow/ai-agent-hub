# CP-105: agent-computer interface

![interfaces](../../assets/icons/interfaces.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `interfaces` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Purpose-built ergonomic commands, concise file viewers, linter hooks, and structured feedback loops tailored for LLM tool consumption rather than humans.

## Why It Matters

Designing interfaces specifically for agents—such as SWE-agent edit tools—significantly boosts task completion over raw human UIs.

## How It Works

Interfaces constrain output line windows, automatically return syntax errors upon edits, and provide focused navigation commands.

## Example

Returning immediate line-numbered diffs and automatic linter feedback whenever a coding agent edits source files.

## Common Mistakes

Exposing noisy human-oriented terminal pagers or full unclipped dumps directly to agent loops.
