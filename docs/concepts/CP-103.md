# CP-103: agent payments and commerce

![business](../../assets/icons/business.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `business` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Protocols and delegated financial controls enabling AI agents to browse catalogs, negotiate carts, and execute authorized checkout transactions.

## Why It Matters

Standardized payment tokens and mandates unlock retail and business-to-business procurement workflows safely without sharing raw card numbers.

## How It Works

Standards like Agentic Commerce Protocol issue scoped, verifiable single-use payment intents or mandates anchored to user limits.

## Example

Completing a user-approved travel itinerary checkout via delegated tokenized payment intents on Stripe.

## Common Mistakes

Handing raw corporate credit card strings directly inside agent context prompts.
