## Definition

Controlled re-execution of failed model requests, transient HTTP errors, or malformed tool calls using exponential backoff and jitter.

## Why It Matters

Distributed API networks experience transient rate limits and timeouts that simple retry policies resolve safely.

## How It Works

Orchestrators classify retryable vs terminal errors, wait using jittered backoff, and pass tool error feedback to let LLMs correct calls.

## Example

Retrying transient rate-limit failures automatically while surfacing invalid parameter schemas back to the model.

## Common Mistakes

Blindly retrying non-idempotent write actions such as payments or emails after ambiguous timeouts.
