# CP-024: context engineering

![foundations](../../assets/icons/foundations.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `foundations` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

The systematic practice of curating, structuring, compressing, and pruning all tokens entering a model's context across multi-turn agent loops.

## Why It Matters

High-signal context prevents attention dilution, context rot, instruction burying, and runaway token expenses.

## How It Works

Systems combine concise system prompts, dynamic retrieval, tool-result clearing, history compaction, and subagent context isolation.

## Example

Summarizing resolved file searches and stripping stale API JSON dumps between coding iterations.

## Common Mistakes

Treating context purely as static prompt wording while neglecting verbose raw tool payloads accumulating in loop history.
