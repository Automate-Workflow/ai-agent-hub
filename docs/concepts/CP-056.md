# CP-056: agent card

![protocols](../../assets/icons/protocols.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `protocols` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

A standardized JSON metadata document published by an A2A-compliant agent advertising its identity, endpoint, capabilities, skills, and auth requirements.

## Why It Matters

Machine-readable Agent Cards power dynamic discovery and capability negotiation in heterogeneous multi-agent networks.

## How It Works

Clients fetch well-known endpoint metadata before selecting an appropriate peer agent and negotiating compatible input/output modalities.

## Example

Discovering an enterprise HR benefits agent's supported OAuth scopes and streaming options from its Agent Card.

## Common Mistakes

Treating unverified public Agent Cards as trusted without signature validation or allowlist governance.
