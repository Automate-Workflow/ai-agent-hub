## Definition

A versioned collection of representative inputs, mock environment fixtures, gold trajectories, and failure edge cases used for repeated testing.

## Why It Matters

High-quality eval sets convert production bugs and user edge cases into permanent quality safeguards.

## How It Works

Teams curate real failure logs alongside synthetic corner cases, labeling expected tool calls, policy rules, and verifiable end states.

## Example

Maintaining a versioned suite of multi-turn refund disputes capturing boundary warranty exceptions.

## Common Mistakes

Using static trivial datasets that fail to evolve alongside real production user behavior.
