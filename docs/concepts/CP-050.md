## Definition

Explicit schema-typed tracking, persistence, and checkpointing of variables, messages, artifacts, and execution cursors across steps.

## Why It Matters

Structured state separation enables pause-and-resume human approvals, replay debugging, and crash recovery.

## How It Works

State objects pass between graph nodes and serialize into persistent checkpointer storage keyed by thread or run ID.

## Example

Persisting pending refund amount, verification flags, and message history across an overnight approval wait.

## Common Mistakes

Mutating unstructured global text blobs instead of typed state reducers with explicit fields.
