# CP-093: rate limiting

![evaluation_and_ops](../../assets/icons/evaluation-and-ops.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `evaluation_and_ops` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Throttling request-per-minute and token-per-minute consumption per tenant, workflow, or external API integration.

## Why It Matters

Proper rate limiting protects upstream provider quotas and shields multi-tenant agents from runaway infinite loops.

## How It Works

Gateways enforce token-bucket counters, queue background batches cleanly, and bound maximum tool invocations per task.

## Example

Capping background indexing throughput so interactive customer chat requests keep priority token quotas.

## Common Mistakes

Allowing unconstrained parallel subagents to trigger cascading rate-limit retries against downstream APIs.
