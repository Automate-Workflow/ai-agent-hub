## Definition

Time elapsed across time-to-first-token, model reasoning generation, network round trips, retrieval queries, and multi-step tool execution.

## Why It Matters

High cumulative multi-step latency breaks conversational voice interactions and hurts interactive developer productivity.

## How It Works

Engineers optimize latency via prompt caching, parallel tool execution, smaller routed models, streaming, and KV-aware inference servers.

## Example

Shrinking voice assistant response delay by routing intent checks to a small fast model.

## Common Mistakes

Measuring only single-call inference latency while ignoring cumulative loop turns and external API bottlenecks.
