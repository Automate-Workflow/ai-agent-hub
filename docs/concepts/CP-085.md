# CP-085: regression testing

![evaluation_and_ops](../../assets/icons/evaluation-and-ops.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `evaluation_and_ops` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Running automated behavioral and safety eval suites on every prompt, model, tool, or retrieval change to catch quality drops early.

## Why It Matters

Because language systems exhibit subtle non-local side effects, fixes in one area frequently break unrelated workflows.

## How It Works

CI pipelines execute fixed eval slices and deterministic trajectory checks, blocking promotion when scores regress past thresholds.

## Example

Triggering automated tool-calling and policy regression tests on every pull request modifying system prompts.

## Common Mistakes

Swapping underlying foundation model versions in production without re-running core safety and schema checks.
