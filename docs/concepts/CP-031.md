# CP-031: short-term memory

![memory_and_knowledge](../../assets/icons/memory-and-knowledge.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `memory_and_knowledge` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Working context retained within a single task run or session thread, including recent messages, scratchpads, and active tool states.

## Why It Matters

Reliable working memory lets agents complete multi-step sequences coherently without repeating completed checks.

## How It Works

Short-term memory resides in the prompt message buffer and thread checkpointer state, pruned or summarized before context saturation.

## Example

Retaining the SQL schema lookup from step two while drafting and validating a query in step four.

## Common Mistakes

Expecting ephemeral conversation buffers to survive across distinct user threads or process restarts without persistence.
