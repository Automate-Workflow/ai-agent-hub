# CP-135: asynchronous background agent

![orchestration](../../assets/icons/orchestration.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `orchestration` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Agent workflows executing detached from synchronous user chat turns, reporting status events and awaiting external triggers or approvals.

## Why It Matters

Long-running tasks like deep CI fixes, incident triage, or large migrations work poorly inside synchronous blocking HTTP requests.

## How It Works

Queued jobs or durable workflows invoke tools asynchronously, emit webhook/event updates, and notify users upon completion or human gates.

## Example

An AWS DevOps or Azure SRE agent investigating alerts asynchronously and posting root-cause summaries to incident channels.

## Common Mistakes

Running multi-minute coding tasks inside synchronous browser request timeouts without job queues.
