# CP-121: multi-agent debate

![reasoning](../../assets/icons/reasoning.svg) ![advanced](../../assets/badges/advanced.svg) ![active](../../assets/badges/active.svg)

**Category:** `reasoning` | **Difficulty:** `advanced` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Having multiple independent model instances critique, challenge, and refine competing hypotheses before converging on a consensus output.

## Why It Matters

Structured peer disagreement lowers overconfident blind spots on complex reasoning and factuality tasks.

## How It Works

Proposer agents generate answers and rationales, inspect peer critiques across rounds, and synthesize revised consensus answers.

## Example

Checking clinical summary accuracy using opposing critic agents verifying claims against source notes.

## Common Mistakes

Letting unanimous shared model biases reinforce errors cleanly across homogeneous ungrounded instances.
