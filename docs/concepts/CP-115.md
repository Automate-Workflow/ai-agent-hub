# CP-115: IO-aware attention (FlashAttention)

![models](../../assets/icons/models.svg) ![advanced](../../assets/badges/advanced.svg) ![active](../../assets/badges/active.svg)

**Category:** `models` | **Difficulty:** `advanced` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Exact attention kernel optimization tiling matrix operations across GPU SRAM and high-bandwidth memory to cut memory overhead and speed long contexts.

## Why It Matters

IO-aware attention makes long-context agent prompts practical without quadratic memory blowups.

## How It Works

Attention blocks fuse softmax normalization and projections inside fast on-chip SRAM without materializing full quadratic score matrices.

## Example

Running hundred-thousand-token repository analysis prompts efficiently on inference servers.

## Common Mistakes

Confusing exact attention optimization with approximate sparse attention that alters model behavior.
