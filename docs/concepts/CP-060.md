## Definition

Reasoning and Acting interleaves explicit natural-language thought traces with environment tool actions and observed feedback in a closed loop.

## Why It Matters

ReAct anchors reasoning in live external observations rather than static internal guesswork, reducing error propagation.

## How It Works

On each step the model produces a reasoning trace explaining what is missing, invokes an external tool, reads the observation, and repeats.

## Example

Searching Wikipedia or documentation step by step until verifying an uncertain multi-hop answer.

## Common Mistakes

Allowing unconstrained ReAct loops without step budgets or loop-detection circuit breakers.
