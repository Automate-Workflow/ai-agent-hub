# CP-112: parameter-efficient fine-tuning (LoRA)

![models](../../assets/icons/models.svg) ![advanced](../../assets/badges/advanced.svg) ![active](../../assets/badges/active.svg)

**Category:** `models` | **Difficulty:** `advanced` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Updating only small trainable low-rank adaptation matrices while keeping base model weights frozen during specialized fine-tuning.

## Why It Matters

Low-rank adaptation drastically shrinks GPU memory needs and lets one shared base model serve numerous specialized agent adapters.

## How It Works

Adapter weights inject low-rank updates alongside attention projections and merge cleanly or swap dynamically per domain task.

## Example

Training lightweight LoRA adapters to enforce proprietary JSON output structures accurately.

## Common Mistakes

Expecting narrow adapter training to compensate for noisy unverified training trajectories.
