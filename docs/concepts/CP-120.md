## Definition

Evaluating agent robustness inside reproducible containerized sandboxes, mock enterprise APIs, or simulated user personas.

## Why It Matters

Realistic simulated sandboxes catch destructive actions safely before agents touch production accounts or customers.

## How It Works

Harnesses such as WebArena, OSWorld, and tau-bench spin up clean stateful environments, score end database/file states, and reset deterministically.

## Example

Running customer-policy adherence tests against a simulated airline reservation database and simulated user agent.

## Common Mistakes

Testing agents solely on static text datasets without stateful API side-effect verification.
