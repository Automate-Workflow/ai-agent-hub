# CP-071: least privilege

![safety_and_security](../../assets/icons/safety-and-security.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `safety_and_security` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Restricting an agent, runtime, and tool token strictly to the minimum permissions, read scopes, and network access needed for the current task.

## Why It Matters

Least privilege caps worst-case damage when an LLM hallucinates tool arguments or encounters indirect prompt injection.

## How It Works

Systems bind per-session scoped tokens, separate read-only vs write credentials, and revoke unused capabilities dynamically.

## Example

Provisioning a read-only database replica user to an analytics agent instead of general write credentials.

## Common Mistakes

Granting workspace admin tokens to every read-only search or summarization agent for convenience.
