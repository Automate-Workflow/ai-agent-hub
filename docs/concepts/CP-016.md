# CP-016: human-in-the-loop

![safety_and_security](../../assets/icons/safety-and-security.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `safety_and_security` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

System design integrating human judgment, oversight, escalation, or explicit confirmation into critical stages of an agent workflow.

## Why It Matters

Human involvement remains essential for irreversible, ambiguous, or regulated decisions where silent errors carry serious impact.

## How It Works

Execution pauses at predefined checkpoints or confidence thresholds, surfaces state context to a reviewer, and resumes only upon user input.

## Example

Requiring a clinician to sign off before AI-drafted clinical coding enters an insurance claim submission.

## Common Mistakes

Flooding human reviewers with low-value confirmations until approval fatigue causes blind rubber-stamping.
