## Definition

Stored rules, skills, system instructions, prompt templates, and learned workflows encoding how an agent performs recurring procedures.

## Why It Matters

Separating reusable skills and procedures from raw facts improves repeatability across complex operational tasks.

## How It Works

Agents either follow authored tool-use playbooks and system instructions or refine successful trajectory templates stored in skill libraries.

## Example

A coding agent loading repository-specific release checklists when preparing deployment pull requests.

## Common Mistakes

Hardcoding procedural skills inside unversioned prompts without testing regression effects when updating instructions.
