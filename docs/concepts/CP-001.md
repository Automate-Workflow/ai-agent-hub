# CP-001: agent

![foundations](../../assets/icons/foundations.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

## Definition

An autonomous or semi-autonomous entity that perceives its environment via sensors or inputs, reasons over state, and executes actions via actuators or tools toward goals.

## Why It Matters

Agents form the foundational unit of all agentic software, separating goal-directed decision loops from static request-response calls.

## How It Works

An observation enters the loop, a policy or model selects an action conditioned on instructions and history, the environment updates, and new feedback arrives.

## Example

A coding assistant inspecting repository files, running tests, reading compiler failures, and editing code until tests pass.

## Common Mistakes

Labeling every single-turn prompt wrapper as an agent even when no iterative feedback loop or tool action exists.
