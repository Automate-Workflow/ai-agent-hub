# CP-130: agentic skill supply chain risk

![safety_and_security](../../assets/icons/safety-and-security.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `safety_and_security` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Vulnerabilities introduced via untrusted third-party MCP servers, community plugins, pre-packaged agent skills, or compromised prompts.

## Why It Matters

Dynamic tool ecosystems create software supply chain exposure where poisoned instructions execute silently inside agent permissions.

## How It Works

Compromised packages tamper with tool docstrings, inject exfiltration payloads, or alter tool routing dynamically via rug pulls.

## Example

Pinning signed tool versions and auditing third-party MCP tool descriptions before deployment.

## Common Mistakes

Installing unpinned unreviewed community agent skills or MCP servers directly into work environments.
