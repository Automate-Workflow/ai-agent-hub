# CP-070: data exfiltration

![safety_and_security](../../assets/icons/safety-and-security.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `safety_and_security` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Unauthorized leakage of confidential secrets, PII, source code, or proprietary files via tool calls, rendered links, or external API parameters.

## Why It Matters

Agents holding broad read permissions alongside outbound HTTP, email, or markdown image tools pose severe exfiltration risk.

## How It Works

Compromised runs encode sensitive context into URL query parameters, webhook bodies, markdown image tags, or outbound messages.

## Example

Rendering a hidden tracking image URL containing URL-encoded API keys inside a generated markdown summary.

## Common Mistakes

Checking only textual chat responses while ignoring outbound URL fetches or tool argument payloads.
