## Definition

Extracting clean structured text, tables, headings, and metadata from heterogeneous PDF, Word, HTML, and slide formats for indexing.

## Why It Matters

Clean ingestion prevents downstream retrieval failures caused by scrambled multi-column text, missing tables, or unreadable scans.

## How It Works

Document loaders apply layout detection, OCR, table extraction, and element classification before chunking.

## Example

Partitioning multi-column technical datasheets with Unstructured to preserve table headers alongside row values.

## Common Mistakes

Applying naive plain-text extraction to scanned PDFs or financial tables without validating layout fidelity.
