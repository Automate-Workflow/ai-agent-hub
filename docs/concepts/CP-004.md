# CP-004: planning

![reasoning](../../assets/icons/reasoning.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `reasoning` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

The capability of an agent to decompose a high-level objective into ordered sub-goals, dependencies, and contingency steps before or during execution.

## Why It Matters

Explicit planning helps agents solve multi-step tasks without losing track of earlier constraints or repeating failed actions.

## How It Works

The model either drafts a full step graph up front or interleaves hierarchical sub-task creation with tool observation feedback.

## Example

An engineering agent breaking a database migration task into schema inspection, backup verification, migration script generation, and integration tests.

## Common Mistakes

Generating brittle multi-step plans without revising them when intermediate tool outputs change task assumptions.
