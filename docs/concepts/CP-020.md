# CP-020: system prompt

![foundations](../../assets/icons/foundations.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `foundations` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Top-level developer instructions separated in model APIs from user turns to define an agent's identity, boundaries, tool rules, and tone.

## Why It Matters

Well-structured system prompts anchor consistent model behavior across diverse user inputs and multi-turn conversations.

## How It Works

Model providers tokenize system messages with higher structural priority ahead of conversational history and retrieved tool results.

## Example

Instructing an analytics agent to never fabricate SQL columns not observed in database schema inspections.

## Common Mistakes

Stuffing exhaustive edge-case manuals or untrusted user text directly into the system prompt.
