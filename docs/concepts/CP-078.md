# CP-078: approval gate

![safety_and_security](../../assets/icons/safety-and-security.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `safety_and_security` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

A mandatory workflow checkpoint pausing execution prior to high-risk or irreversible actions until an authorized human confirms or rejects parameters.

## Why It Matters

Approval gates protect sensitive state changes such as payments, production writes, deletions, and external emails.

## How It Works

Before dispatching a flagged tool call, the runtime checkpoints state, presents exact diff or parameters to an operator, and awaits resume.

## Example

Pausing a DevOps agent before running a production database schema drop until an on-call engineer clicks approve.

## Common Mistakes

Showing vague natural-language summaries instead of the exact concrete parameters that will execute upon approval.
