# CP-086: observability

![evaluation_and_ops](../../assets/icons/evaluation-and-ops.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `evaluation_and_ops` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Full visibility into live agent execution states, traces, token usage, latency bottlenecks, error modes, and retrieval behavior in production.

## Why It Matters

Observability turns opaque multi-step failures into diagnosable engineering signals.

## How It Works

SDKs and telemetry exporters stream structured spans, prompt parameters, tool latencies, and user feedback into dashboards.

## Example

Tracing why a booking agent stalled for thirty seconds due to repeated invalid date tool retries.

## Common Mistakes

Monitoring only HTTP server status codes while ignoring silent tool loops, empty retrievals, and hallucinated replies.
