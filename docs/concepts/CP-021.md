# CP-021: context window

![models](../../assets/icons/models.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `models` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

The maximum sequence length measured in tokens that a language model can attend to in a single forward pass, covering inputs and outputs.

## Why It Matters

Context capacity limits how much history, tool schema, retrieved knowledge, and scratchpad reasoning an agent sees at once.

## How It Works

Self-attention computes pairwise token interactions across the active window; exceeding capacity forces truncation or degradation.

## Example

Compacting old conversation turns before a long debugging session saturates model context attention.

## Common Mistakes

Assuming filling an entire maximum token window preserves equal recall across early and middle instructions.
