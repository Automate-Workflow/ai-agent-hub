# CP-014: episodic memory

## Definition

Long-term storage and retrieval of past interaction episodes, experiences, actions taken, and outcomes tied to specific contexts or sessions.

## Why It Matters

Episodic memory lets an agent recall user preferences, prior bug fixes, and previous negotiation history instead of starting blank.

## How It Works

Completed interactions are summarized with metadata and timestamps, indexed in persistent storage, and recalled by recency and relevance.

## Example

Recalling that a returning engineering user prefers pytest fixtures over unittest boilerplate from prior coding sessions.

## Common Mistakes

Writing noisy raw logs directly into episodic stores without deduplication or expiration rules.
