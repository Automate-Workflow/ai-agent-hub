# CP-069: indirect prompt injection

![safety_and_security](../../assets/icons/safety-and-security.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `safety_and_security` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

An attack embedded inside external data retrieved by an agent—such as emails, web pages, PDFs, or issues—that hijacks execution upon ingestion.

## Why It Matters

Any agent reading external untrusted content while holding write tools can be weaponized without direct user malice.

## How It Works

Malicious directives hidden in fetched HTML, document comments, or RAG chunks steer subsequent tool calls toward attacker goals.

## Example

A calendar invite description containing hidden instructions telling an assistant to forward private emails externally.

## Common Mistakes

Treating RAG passages or third-party tickets as trusted instructions instead of untrusted data.
