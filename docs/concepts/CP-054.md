## Definition

Model Context Protocol is an open specification standardizing how AI host applications connect securely to external context, prompts, and tools.

## Why It Matters

MCP eliminates custom N-by-M glue code between every agent host and external tool or data integration.

## How It Works

MCP clients inside host apps communicate over JSON-RPC with stdio or Streamable HTTP MCP servers exposing resources, tools, and prompts.

## Example

Connecting an IDE coding assistant to an internal issue tracker and repository server over a standardized MCP interface.

## Common Mistakes

Deploying third-party MCP servers blindly without validating tool descriptions against hidden prompt-injection instructions.
