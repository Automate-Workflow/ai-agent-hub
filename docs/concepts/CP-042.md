## Definition

Attaching verifiable references linking generated agent statements back to exact retrieved source documents, spans, or tool outputs.

## Why It Matters

Fine-grained citations enable rapid human audit and build justified trust in high-stakes research, legal, and medical outputs.

## How It Works

Generation pipelines pass indexed document blocks and instruct or natively force the model to output verified span references.

## Example

Citing the exact clause page and snippet returned by retrieval inside a regulatory compliance brief.

## Common Mistakes

Displaying plausible-looking URLs or footnote numbers generated from memory rather than retrieved source documents.
