# CP-006: adaptive learning in agents

## Definition

Mechanisms by which an agent improves future behavior from execution feedback, critic evaluations, or parameter updates over repeated episodes.

## Why It Matters

Adaptation turns static one-off trial-and-error runs into accumulating organizational capability.

## How It Works

Agents either store distilled verbal lessons into long-term episodic memory or update model weights via reinforcement or fine-tuning.

## Example

A Reflexion loop recording why a SQL query timed out so subsequent attempts add selective filters immediately.

## Common Mistakes

Allowing unvetted self-modifying feedback to persist erroneous heuristics or poisoned instructions.
