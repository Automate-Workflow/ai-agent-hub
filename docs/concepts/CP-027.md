## Definition

End-to-end GUI and desktop control where a multimodal agent perceives screen pixels and dispatches mouse, keyboard, and shell actions across arbitrary software.

## Why It Matters

Computer use extends automation beyond APIs and browsers into native desktop tools, legacy GUIs, and operating-system workflows.

## How It Works

A multimodal policy inspects periodic desktop screenshots, predicts target coordinates and keystrokes, executes actions via OS sandboxes, and observes updated screens.

## Example

Installing test dependencies, opening a spreadsheet tool, formatting metrics, and saving a report in a sandboxed VM.

## Common Mistakes

Running GUI agents without confirmation gates on financial, email, or administrative windows exposed to untrusted content.
