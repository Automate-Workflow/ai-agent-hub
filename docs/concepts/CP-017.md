## Definition

Constraining model generation so responses conform deterministically to typed JSON schemas or typed object models.

## Why It Matters

Reliable structured outputs let downstream application code parse agent decisions safely without fragile string scraping.

## How It Works

Constrained decoding grammars or strict schema enforcement restrict allowable next tokens to valid keys, enums, and value types.

## Example

Returning a strictly typed Pydantic classification record containing severity, component, and citation references.

## Common Mistakes

Validating JSON only via post-hoc string cleanup when constrained schema decoding is natively available.
