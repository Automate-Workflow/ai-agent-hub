## Definition

A standardized, reproducible task suite and scoring protocol enabling apples-to-apples comparison across models, scaffolds, and agent runs.

## Why It Matters

Public agent benchmarks expose real multi-step weaknesses in coding, web navigation, tool usage, and long-horizon reliability.

## How It Works

Reproducible harnesses provide fixed environments, repositories, or user simulators and grade final state verification automatically.

## Example

Evaluating coding agents on isolated GitHub repository test patches using SWE-bench.

## Common Mistakes

Treating benchmark leaderboard saturation or contaminated pre-training tasks as proof of domain production readiness.
