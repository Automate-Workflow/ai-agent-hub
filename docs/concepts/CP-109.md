# CP-109: context compaction

**Category:** `memory_and_knowledge` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Periodically summarizing resolved conversation history or older tool observations into dense state digests to stay within attention budgets.

## Why It Matters

Compaction preserves essential task facts and constraints across long sessions without hitting context-window saturation or rot.

## How It Works

Before exceeding threshold capacity, a summarization pass distills resolved decisions, modified files, and open goals into a clean state block.

## Example

Summarizing fifty turns of repo exploration into a concise index of key symbols before starting edits.

## Common Mistakes

Allowing compaction summaries to drop subtle boundary constraints, file paths, or exact error messages.
