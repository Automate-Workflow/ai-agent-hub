## Definition

Specialized storage and approximate nearest-neighbor indexing engines optimized for similarity search and metadata filtering over high-dimensional vectors.

## Why It Matters

Vector stores provide low-latency retrieval across millions of embedded document chunks and agent memories.

## How It Works

Indices such as HNSW or IVF organize embedding vectors alongside scalar payloads to support filtered semantic queries.

## Example

Querying Qdrant or pgvector with both tenant permission filters and semantic query vectors.

## Common Mistakes

Deploying complex distributed vector clusters when hybrid SQL full-text or small local indices would satisfy workload scale.
