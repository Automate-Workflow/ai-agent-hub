# CP-015: policy constraints and action bounds

![safety_and_security](../../assets/icons/safety-and-security.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `safety_and_security` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Explicit machine-enforced rules specifying spending caps, allowable domains, rate quotas, and restricted operations an agent cannot cross.

## Why It Matters

Clear action bounds allow autonomous systems to operate productively while capping blast radius from reasoning errors.

## How It Works

Deterministic policy engines intercept proposed tool parameters before execution and verify compliance against signed enterprise limits.

## Example

Capping an autonomous procurement agent at pre-approved vendor catalogs and single-order dollar limits.

## Common Mistakes

Relying exclusively on natural-language prompt warnings instead of external server-side enforcement.
