## Definition

Splitting source documents into coherent, sized passages with structural boundaries and metadata before indexing for retrieval.

## Why It Matters

Chunk geometry directly controls retrieval precision and whether answers keep enough surrounding context to remain accurate.

## How It Works

Pipelines segment text by headings, markdown sections, semantic shifts, or overlapping token windows while attaching section headers.

## Example

Partitioning a technical specification by H2/H3 section boundaries while preserving parent document titles in metadata.

## Common Mistakes

Cutting arbitrarily at fixed character offsets mid-table or mid-code-block, destroying structural meaning.
