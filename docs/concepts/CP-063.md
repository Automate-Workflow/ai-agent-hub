## Definition

A self-evaluation phase where an agent or separate critic model reviews generated outputs or execution failures to produce corrective feedback.

## Why It Matters

Structured critique systematically catches logic bugs, missing citations, schema misses, and style violations prior to delivery.

## How It Works

After a draft or test failure, an evaluator examines outputs against rubric criteria and feeds specific improvement notes back to the generator.

## Example

Reviewing a generated SQL query against execution error output and correcting a column join typo on iteration two.

## Common Mistakes

Running open-ended self-critique without external ground truth such as unit tests, schemas, or rubrics.
