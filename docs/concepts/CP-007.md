# CP-007: conversation state and turns

![interfaces](../../assets/icons/interfaces.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `interfaces` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Structured management of alternating user, assistant, system, and tool messages across a multi-turn session.

## Why It Matters

Consistent turn tracking preserves intent, resolved ambiguities, and tool execution context during ongoing dialogue.

## How It Works

Applications persist typed message histories or server-side conversation IDs and supply pruned or summarized turns to each model invocation.

## Example

A voice support session remembering an authenticated account ID from turn one when issuing a billing adjustment in turn four.

## Common Mistakes

Dropping tool-call IDs or assistant messages out of turn order, violating model API pairing invariants.
