# CP-081: evaluation

![evaluation_and_ops](../../assets/icons/evaluation-and-ops.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `evaluation_and_ops` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Systematic measurement of agent accuracy, tool correctness, grounding, safety, latency, and cost against defined tasks and rubrics.

## Why It Matters

Without rigorous evaluation, teams ship silent regressions whenever prompts, models, retrieval indices, or tool schemas change.

## How It Works

Automated harnesses execute agents across curated test suites, apply deterministic assertions and graded checks, and aggregate pass rates.

## Example

Scoring a customer support agent on policy compliance, exact tool arguments, and faithfulness before deployment.

## Common Mistakes

Judging production readiness purely on casual manual vibe checks over three happy-path examples.
