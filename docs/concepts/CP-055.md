## Definition

Agent2Agent is an open protocol enabling opaque, independent AI agents across vendors and runtimes to discover capabilities and collaborate on tasks.

## Why It Matters

Agent-to-agent protocols let enterprise systems interoperate across organizational and framework boundaries without exposing internal prompts or proprietary tools.

## How It Works

Agents publish JSON Agent Cards describing skills and auth, then exchange lifecycle task messages and artifacts over HTTP/JSON-RPC/SSE.

## Example

A customer-facing travel agent delegating flight rebooking tasks to a partner airline agent via A2A.

## Common Mistakes

Confusing A2A inter-agent delegation with MCP agent-to-tool integration rather than pairing them as complementary layers.
