**Category:** `models` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Adapting pre-trained foundation model weights on curated domain demonstrations or preference data to specialize tone, schemas, or tool behaviors.

## Why It Matters

Fine-tuning can distill complex multi-page prompt rules into compact models while improving speed and task consistency.

## How It Works

Supervised training updates full parameters or low-rank adapters (LoRA) over verified trajectories and domain datasets.

## Example

Fine-tuning an open-weight model via LoRA on validated repository navigation trajectories.

## Common Mistakes

Fine-tuning early to inject fast-changing facts when RAG or better prompt engineering solves the actual gap.
