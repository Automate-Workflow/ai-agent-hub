# CP-049: handoff

![orchestration](../../assets/icons/orchestration.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `orchestration` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Explicit transfer of execution control, user session state, and responsibility from one agent or human operator to another.

## Why It Matters

Clean handoffs allow seamless specialist transitions in multi-agent systems and smooth escalation to live human staff.

## How It Works

An active agent invokes a designated handoff tool carrying typed state and rationale, swapping the active prompt and toolset cleanly.

## Example

A triage support agent handing off an approved billing refund request directly to a payments specialist agent.

## Common Mistakes

Executing handoffs that discard prior constraints or trap two agents in mutual ping-pong transfers.
