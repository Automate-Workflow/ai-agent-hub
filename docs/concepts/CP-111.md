# CP-111: subagent context isolation

![orchestration](../../assets/icons/orchestration.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `orchestration` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Delegating focused exploration or review sub-tasks to short-lived subagents running inside clean separate context windows.

## Why It Matters

Context isolation stops noisy file searches and intermediate failed branches from polluting the main coordinator's focus.

## How It Works

A parent agent passes a scoped prompt to a subagent that runs its own tool loop and returns only a concise verified summary.

## Example

Sending a coding subagent to audit ten test files and return only failing assertions to the lead agent.

## Common Mistakes

Spawning heavy nested subagents for trivial single-file lookups where direct tool calls are faster.
