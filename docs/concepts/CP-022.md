# CP-022: tool calling

![tools_and_actions](../../assets/icons/tools-and-actions.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `tools_and_actions` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

The capability of an LLM to generate structured tool invocation requests matching registered schemas so host software can execute external actions.

## Why It Matters

Tool calling bridges static text generation with live databases, calculators, APIs, and code execution.

## How It Works

Registered tool names, descriptions, and parameter schemas are passed to the model; when needed, the model emits a call object instead of plain text.

## Example

Emitting a structured `search_orders` tool call with customer email before answering a shipping status question.

## Common Mistakes

Giving an agent dozens of overlapping undocumented tools, confusing selection and inflating token costs.
