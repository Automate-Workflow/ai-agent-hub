## Definition

Sampling multiple independent reasoning paths for the same prompt and selecting the most consistent consensus final answer.

## Why It Matters

Majority voting across diverse reasoning chains improves robustness on high-stakes classification, math, and extraction tasks.

## How It Works

Multiple completions run at non-zero temperature, extract normalized answers, and aggregate votes or verifier scores.

## Example

Running three independent vulnerability triage assessments and escalating when consensus fails.

## Common Mistakes

Paying multiplied token latency without checking whether agreement actually correlates with factual correctness.
