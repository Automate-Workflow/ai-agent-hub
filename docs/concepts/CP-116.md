**Category:** `evaluation_and_ops` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Serving cached agent responses when incoming queries embed within strict similarity thresholds of previously verified answers.

## Why It Matters

Semantic caching lowers inference expenses and latency on repetitive FAQ or documentation traffic.

## How It Works

Queries are embedded, searched against recent cache vectors with strict metadata filters, and returned directly if similarity passes bounds.

## Example

Serving repeated public pricing FAQ answers immediately from vector cache while bypassing full tool execution.

## Common Mistakes

Returning stale or cross-tenant cached replies when query filters, permissions, or freshness parameters differ.
