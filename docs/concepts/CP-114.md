# CP-114: speculative decoding

![models](../../assets/icons/models.svg) ![advanced](../../assets/badges/advanced.svg) ![active](../../assets/badges/active.svg)

**Category:** `models` | **Difficulty:** `advanced` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Inference acceleration technique using a lightweight draft model to propose multiple tokens verified in parallel by a larger target model.

## Why It Matters

Speculative decoding lowers interactive generation latency without altering output probability distributions.

## How It Works

A small fast draft predicts candidate token chunks that the larger model checks in a single batched forward pass.

## Example

Serving high-throughput agent completions faster via draft-model speculation on vLLM.

## Common Mistakes

Enabling draft models whose vocabulary or domain distribution diverges heavily, lowering acceptance rates.
