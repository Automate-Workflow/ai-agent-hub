# CP-128: durable execution

![orchestration](../../assets/icons/orchestration.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `orchestration` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Runtime execution model persisting workflow state and completed side-effect logs so multi-day agent tasks recover deterministically after crashes.

## Why It Matters

Durable execution prevents duplicate charges, lost progress, and zombie tasks across unstable networks and overnight human approvals.

## How It Works

Engines such as Temporal journal activity results and replay control flow cleanly from checkpoints upon worker restarts.

## Example

Running an enterprise onboarding workflow that pauses days for background checks without losing state.

## Common Mistakes

Storing multi-hour agent execution progress exclusively inside ephemeral in-memory web worker processes.
