# CP-058: tool schema contract

**Category:** `tools_and_actions` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Formal specification of a tool's name, purpose, parameter JSON Schema, expected side-effect flags, and return payload structure.

## Why It Matters

Precise contracts dramatically reduce malformed tool calls and make permission policies auditable.

## How It Works

Schemas declare typed arguments, constraints, and descriptions that models read at inference time and runtimes validate pre-execution.

## Example

Annotating read-only search tools separately from state-mutating write endpoints with explicit parameter constraints.

## Common Mistakes

Using vague parameter names like `data` or `input` without format descriptions or value enums.
