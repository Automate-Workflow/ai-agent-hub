# CP-043: grounding

![evaluation_and_ops](../../assets/icons/evaluation-and-ops.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `evaluation_and_ops` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Anchoring model outputs strictly in verified retrieved evidence, live tool state, or sensor observations rather than parametric memory alone.

## Why It Matters

Strong grounding constrains fabricated claims and enforces faithful adherence to supplied organizational context.

## How It Works

Architectures pass authoritative facts via retrieval or tools, prompt for evidence-only answers, and verify entailment via judges or citations.

## Example

Requiring a benefits assistant to return an explicit unknown notice when policy documents lack an answer.

## Common Mistakes

Prompting an agent to answer only from sources while still letting it invent unsupported advice when retrieval returns empty.
