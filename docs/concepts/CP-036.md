# CP-036: embeddings

## Definition

Dense numerical vectors generated by encoder models to capture semantic similarity between text, code, or multimodal items in vector space.

## Why It Matters

Vector representations allow semantic retrieval even when queries use synonyms different from exact document keywords.

## How It Works

An embedding model projects chunks and queries into fixed-dimension vectors so nearest-neighbor distance identifies conceptually related items.

## Example

Matching a customer query about delayed packages to shipping SLA sections mentioning transit carrier delays.

## Common Mistakes

Mixing vectors created by incompatible embedding models inside the same index without re-indexing.
