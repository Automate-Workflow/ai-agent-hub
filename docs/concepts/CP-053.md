# CP-053: guided multi-turn workflow

![interfaces](../../assets/icons/interfaces.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `interfaces` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Combining natural-language dialogue with structured step progression, validation checks, and dynamic slot filling to complete multi-step forms or intakes.

## Why It Matters

Conversational guidance lowers user drop-off on complex intakes while preserving backend data integrity.

## How It Works

An agent tracks missing required schema fields across turns, asks clarifying questions naturally, and triggers actions once complete.

## Example

Walking a mortgage applicant through income documentation checks and explaining missing checklist items.

## Common Mistakes

Asking users confusing free-form questions without confirming parsed dates, amounts, or policy constraints.
