# CP-026: browser automation

![interfaces](../../assets/icons/interfaces.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `interfaces` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Programmatic control of web browsers by agents to navigate pages, inspect DOM accessibility trees, fill forms, and extract dynamic web content.

## Why It Matters

Browser automation lets agents interact with web applications that lack public APIs or require multi-step UI navigation.

## How It Works

Libraries like Playwright capture DOM snapshots or screenshots, map interactive element IDs, and execute click or type actions per turn.

## Example

Navigating an internal procurement portal to download monthly PDF invoices for accounting reconciliation.

## Common Mistakes

Using fragile CSS selectors without visual or accessibility-tree grounding, breaking on minor web layout updates.
