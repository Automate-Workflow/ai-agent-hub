## Definition

The property allowing independent observers to inspect claims, deterministic checks, citations, and execution logs to confirm correctness.

## Why It Matters

Verifiability separates trustworthy production agents from black-box chatbots in regulated and engineering domains.

## How It Works

Architectures attach source spans, runnable unit tests, schema validations, and signed audit trails to every outcome.

## Example

Requiring coding agents to show passing test logs alongside referenced modified file lines.

## Common Mistakes

Treating confident natural-language explanations by an LLM as proof that actions actually succeeded.
