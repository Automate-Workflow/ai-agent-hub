# CP-025: code execution by agents

![tools_and_actions](../../assets/icons/tools-and-actions.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `tools_and_actions` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Granting an agent the ability to author, run, inspect, and iteratively debug programmatic code to solve computation or repository tasks.

## Why It Matters

Executing real code gives agents exact arithmetic, data parsing, file editing, and verifiable automated feedback.

## How It Works

The model emits scripts or shell commands executed inside controlled runtimes, then reads stdout, stderr, and test exit codes to iterate.

## Example

Writing a Python data analysis script inside an isolated container to summarize CSV trends reliably.

## Common Mistakes

Running model-generated scripts directly on unisolated host machines with access to production secrets.
