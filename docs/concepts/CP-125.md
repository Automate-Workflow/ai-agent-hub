## Definition

Inherent variability across repeated LLM agent runs caused by sampling, parallel floating-point order, and shifting external environments.

## Why It Matters

Single-pass eval scores mask flaky agents whose success drops steeply when measured across repeated independent trials (pass^k).

## How It Works

Teams lower variance via zero temperature, seed controls, deterministic schemas, and repeated trial pass^k benchmarks.

## Example

Running eight independent trials on tau-bench to verify consistent policy compliance across runs.

## Common Mistakes

Deploying an agent after one lucky test run without measuring multi-trial consistency.
