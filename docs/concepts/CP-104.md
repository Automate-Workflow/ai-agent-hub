## Definition

Complex multi-hour or multi-day objectives spanning numerous tool steps, context compactions, intermediate checkpoints, and error recoveries.

## Why It Matters

Real software engineering, research synthesis, and incident response frequently exceed single short context interactions.

## How It Works

Agents combine durable execution queues, external scratchpad files, periodic summaries, and state checkpointers to survive restarts.

## Example

Migrating an entire repository test framework module by module with durable state tracking.

## Common Mistakes

Running long-horizon loops cleanly inside one brittle memory-only chat loop without persistent checkpoints.
