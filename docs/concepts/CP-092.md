## Definition

Automated failover routing across alternative models, inference endpoints, degraded workflows, or human escalation upon errors or timeouts.

## Why It Matters

Resilient fallback chains keep user-facing services available during single-provider outages or rate-limit spikes.

## How It Works

Model gateways catch HTTP errors or schema validation failures and transparently switch to configured secondary models or safe responses.

## Example

Routing requests through LiteLLM from a primary API endpoint to a backup region or provider upon timeouts.

## Common Mistakes

Failing over to a weak fallback model with unsafe instruction compliance on high-risk actions without re-checking schemas.
