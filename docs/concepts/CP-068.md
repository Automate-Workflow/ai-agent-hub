# CP-068: prompt injection

![safety_and_security](../../assets/icons/safety-and-security.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `safety_and_security` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

An attack class where adversarial user text overrides system instructions, hijacks goals, or coerces unauthorized model behavior and tool calls.

## Why It Matters

Because LLMs process instructions and untrusted text inside one token stream, prompt injection is a primary agent security risk.

## How It Works

Crafted adversarial strings exploit instruction-following tendency to extract hidden prompts, bypass filters, or force forbidden tool calls.

## Example

A user appending hidden override commands to extract internal system prompts or trigger unauthorized refund tools.

## Common Mistakes

Assuming polite instruction phrasing or blacklist word filters stops creative prompt injection payloads.
