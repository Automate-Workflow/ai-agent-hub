## Definition

Training and guiding models via explicit written principle constitutions using AI feedback critique rather than human labels alone.

## Why It Matters

Explicit normative constitutions make behavioral safety expectations inspectable, editable, and scalable.

## How It Works

Models critique and revise harmful initial outputs against written constitutional rules, distilling safer preference models via RLAIF.

## Example

Using clear harmlessness principles during model training to reduce refusal inconsistency.

## Common Mistakes

Treating static written constitutions as substitutes for runtime authorization boundaries and sandboxing.
