# CP-110: tool-result clearing

![foundations](../../assets/icons/foundations.svg) ![intermediate](../../assets/badges/intermediate.svg) ![active](../../assets/badges/active.svg)

**Category:** `foundations` | **Difficulty:** `intermediate` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

Pruning or replacing bulky raw historical tool outputs (such as large HTML fetches or directory listings) after the agent extracts needed insights.

## Why It Matters

Stripping stale verbose payloads prevents single tool calls from crowding out essential instructions across subsequent turns.

## How It Works

Context managers retain the tool call summary or extracted key facts while replacing older full payloads with brief references.

## Example

Clearing raw megabyte log dumps from earlier turns once anomalous timestamps are saved to state.

## Common Mistakes

Deleting recent tool results that the immediately following reasoning step still needs to quote verbatim.
