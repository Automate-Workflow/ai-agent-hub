## Definition

Using a calibrated language model with structured rubrics to score open-ended text quality, faithfulness, tone, and reasoning trajectories.

## Why It Matters

Automated model judges scale nuance grading across thousands of outputs where exact string matching fails.

## How It Works

A judge model receives inputs, reference criteria, and system responses (or pairwise outputs) and emits structured scores and rationales.

## Example

Grading whether a support explanation covers all policy nuances faithfully compared to retrieved documents.

## Common Mistakes

Trusting uncalibrated judges blindly without validating correlation against human expert annotations and position bias.
