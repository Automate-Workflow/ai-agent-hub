## Definition

Reusing computed prompt prefixes (KV cache), embedding lookups, tool responses, or semantically identical answers to cut latency and cost.

## Why It Matters

Prompt prefix caching makes long static system instructions, few-shot examples, and tool catalogs far cheaper across loops.

## How It Works

Inference providers store key-value attention states keyed by exact token prefixes, while gateways optionally cache deterministic tool calls.

## Example

Keeping static tool definitions and compliance policy instructions at the prompt prefix to preserve cache hits.

## Common Mistakes

Placing dynamic timestamps or shuffled tool lists at the start of prompts, busting prefix cache hits on every turn.
