## Definition

A declarative vocabulary standard for describing the structure, required fields, types, enums, and regex constraints of JSON data.

## Why It Matters

JSON Schema serves as the universal contract between LLMs, tool definitions, MCP servers, and API validators.

## How It Works

Schema documents declare expected object properties and constraints that validators and constrained model decoders check before tool execution.

## Example

Defining strict `required` properties and string regex patterns on tool parameters for calendar booking.

## Common Mistakes

Writing vague tool schemas lacking descriptions or enums, causing models to hallucinate parameter formats.
