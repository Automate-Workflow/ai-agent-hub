# CP-003: LLM

![models](../../assets/icons/models.svg) ![beginner](../../assets/badges/beginner.svg) ![active](../../assets/badges/active.svg)

**Category:** `models` | **Difficulty:** `beginner` | **Confidence:** `high` | **Status:** `active` | **Verified:** `2026-11-11`

## Definition

A large language model built on Transformer neural architectures trained on vast text and code corpora to predict tokens and follow instructions.

## Why It Matters

Modern LLMs act as the core reasoning, planning, and interface engine inside language-based agents.

## How It Works

Input tokens pass through stacked self-attention layers that weigh contextual relationships before sampling the next output token or tool invocation.

## Example

A frontier Transformer model interpreting user tickets, extracting structured fields, and invoking lookup APIs.

## Common Mistakes

Treating an LLM as a deterministic database rather than a probabilistic generator capable of plausible errors.
