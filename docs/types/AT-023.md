# AT-023: supervisor_orchestrator

## Definition

The top-level agent in a hierarchy that plans, delegates to workers, monitors quality and manages the overall workflow end-to-end.

## How It Works

Receives the user goal; produces a structured work plan; dispatches subtasks to appropriate worker agents; collects results; evaluates quality (possibly using an evaluator agent); retries or reassigns failed steps; assembles the final deliverable and reports to the user.

## Strengths

Centralises coordination; enables parallelism; natural audit trail through the orchestrator; can enforce global constraints and policies.

## Limitations

Orchestrator context window grows with task size; orchestrator failure blocks the entire pipeline; requires the orchestrator to have full visibility of the problem domain.

## Typical Examples

LangGraph supervisor node, AutoGen UserProxy manager, CrewAI process manager, A2A orchestrator agent.
