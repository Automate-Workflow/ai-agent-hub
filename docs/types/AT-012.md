## Definition

Generates, reviews, debugs and executes code to solve software engineering tasks, interacting with IDEs, terminals and code repositories.

## How It Works

Receives a software task description; generates code using an LLM; executes it in a sandboxed environment; analyses the output or error; iterates by editing and re-running until tests pass or the task is complete. Can interact with git, linters and package managers.

## Strengths

Dramatically accelerates software development; can iterate autonomously; handles boilerplate; integrates with existing toolchains.

## Limitations

May generate plausible but incorrect code; sandbox escapes are a security risk; lacks understanding of large-codebase architecture without context; can introduce subtle bugs.

## Typical Examples

GitHub Copilot Workspace, Devin, Claude Code, Cursor Agent, OpenAI Codex agent.
