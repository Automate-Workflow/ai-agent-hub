## Definition

Maintains and queries a structured knowledge base as its primary mode of action, using retrieval and reasoning over stored structured knowledge.

## How It Works

Connects to one or more knowledge stores (graph DB, relational DB, ontology, structured KB). Receives queries; translates them into KB query language (SPARQL, Cypher, SQL); retrieves facts; reasons over the returned structured data to produce an answer; can also update the KB with new information.

## Strengths

Highly accurate for queries within the KB's scope; transparent and auditable; deterministic for factual lookups; supports complex multi-hop reasoning via graph traversal.

## Limitations

Requires a well-maintained KB; KB coverage limits answer scope; natural language to query translation can fail; KB updates require validation to prevent corruption.

## Typical Examples

Enterprise knowledge graph agents, Wolfram Alpha-style computational knowledge agents, drug interaction lookup agents, ontology-grounded medical agents.
