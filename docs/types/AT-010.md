## Definition

Processes and reasons over images, video or other non-text modalities alongside text to accomplish tasks requiring cross-modal understanding.

## How It Works

Accepts inputs in multiple modalities (image, audio, video, text). A multimodal encoder (vision transformer, audio encoder) converts each modality to tokens in a shared embedding space. The LLM backbone reasons over all tokens jointly to produce a text or structured output.

## Strengths

Solves tasks impossible for text-only models; can inspect charts, diagrams and scenes; enables visual QA, document parsing, and image-based code generation.

## Limitations

Multimodal models are larger and slower; image inputs consume many tokens; hallucinations can occur on fine visual details; video processing is expensive.

## Typical Examples

GPT-4V image analysis, Gemini multimodal reasoning, visual document parsing, medical image analysis assistants.
