## Definition

An agent in a network where agents communicate directly with each other without a central orchestrator, negotiating and coordinating autonomously.

## How It Works

Agents maintain a local view of the network and discover peers via a directory or gossip protocol. They send messages directly to relevant peers using an agreed protocol (A2A, custom RPC). Coordination emerges from local rules and negotiation rather than central control. Consensus mechanisms resolve conflicts.

## Strengths

Highly resilient with no central point of failure; scales naturally; enables emergent cooperative behaviour; appropriate for decentralised environments.

## Limitations

Harder to reason about system-wide behaviour; debugging requires distributed tracing; consensus mechanisms add overhead; security is more complex without a central authority.

## Typical Examples

Federated learning participants, A2A peer agents, autonomous negotiation agents in supply-chain markets, distributed sensor fusion agents.
