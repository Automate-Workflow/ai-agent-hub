## Definition

Manages a user's tasks, calendar, email and information needs as a persistent, personalised helper with memory across sessions.

## How It Works

Maintains a user model and personal memory store. On each interaction, retrieves relevant context (past preferences, ongoing tasks, calendar state) and uses tools (email APIs, calendar APIs, task managers, search) to fulfil requests. Writes outcomes back to memory for future reference.

## Strengths

Personalised over time; proactively surfaces relevant information; reduces cognitive load; integrates disparate personal information.

## Limitations

Requires broad API access raising privacy concerns; mistakes in autonomous actions (sent emails, deleted events) are hard to reverse; trust calibration is difficult.

## Typical Examples

Apple Intelligence, Microsoft 365 Copilot personal assistant, Notion AI assistant, custom AI executive assistant bots.
