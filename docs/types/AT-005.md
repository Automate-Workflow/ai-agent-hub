## Definition

Has a learning element that improves performance from experience using feedback signals, gradually refining its behaviour policy over time.

## How It Works

Contains four components: performance element (acts), critic (evaluates actions against a standard), learning element (improves performance element using critic feedback), and problem generator (proposes exploratory actions). Feedback drives policy updates via RL, supervised fine-tuning or other learning algorithms.

## Strengths

Improves automatically over time; can adapt to environments too complex to hand-code; generalises from examples to novel situations.

## Limitations

Requires significant data and compute to train; learning can be unstable; may exploit reward functions in unintended ways; requires careful design of feedback signals.

## Typical Examples

RLHF-trained LLM assistants, reinforcement learning game agents (AlphaGo, OpenAI Five), self-improving code-generation agents.
