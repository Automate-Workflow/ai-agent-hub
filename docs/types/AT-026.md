## Definition

Decomposes high-level goals into structured plans (steps, dependencies, assignments) without necessarily executing them, providing a roadmap for other agents.

## How It Works

Receives a goal; analyses it to identify required steps, their dependencies and the best order of execution; identifies which tools or agent types each step requires; produces a machine-readable plan (JSON DAG, task list); hands the plan to an executor or orchestrator.

## Strengths

Separation of concerns enables better planning quality; plan can be reviewed by humans or validators before execution; planner can optimise task ordering for parallelism.

## Limitations

Planning quality degrades for tasks requiring real-time information not available at plan time; plan can become stale as execution proceeds; adds an extra LLM call before work begins.

## Typical Examples

GPT-4 task planner in AutoGPT, LLM-based DAG planner in LangGraph, strategic planning agents in multi-agent research systems.
