# AT-029: memory_augmented_agent

## Definition

An agent with persistent external memory that it reads and writes across sessions, enabling personalisation, continuity and accumulation of knowledge over time.

## How It Works

At the start of each session, the agent queries its memory store (vector DB, key-value store or graph DB) with the current context to retrieve relevant past information. During and after the session it writes new facts, decisions and summaries back to memory. Future sessions benefit from accumulated knowledge.

## Strengths

Enables personalisation that improves over time; overcomes context window limits; supports long-horizon task continuity across sessions.

## Limitations

Memory retrieval can surface stale or incorrect information; privacy concerns with persistent user data; memory management (forgetting, updating) is complex; storage costs grow over time.

## Typical Examples

MemGPT/Letta agents, Zep-augmented agents, custom agents with Pinecone or Weaviate long-term memory, personal AI assistants.
