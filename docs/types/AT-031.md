## Definition

One member of a swarm: a lightweight agent that works in parallel with many identical or similar agents on decomposed subtasks, with no central coordinator.

## How It Works

A task is split into independent shards. Identical or similar agents are instantiated for each shard. Each agent processes its shard independently, posts results to a shared blackboard or message bus. A merge step aggregates results. Agents may also communicate peer-to-peer to avoid duplicate work.

## Strengths

Massively parallel; horizontally scalable; individual agent failures do not stop the swarm; no single point of coordination failure.

## Limitations

Requires careful task decomposition to avoid conflicts; merge logic must handle partial failures; communication overhead grows with swarm size; emergent coordination bugs are hard to debug.

## Typical Examples

Particle swarm optimisation agents, parallelised web scraping agents, distributed document processing swarms, test-generation agent swarms.
