## Definition

Has explicit goals and searches for action sequences that lead to goal states, enabling planning beyond the immediate next action.

## How It Works

Represents the current state, one or more goal states, and a set of possible actions. Uses search algorithms (BFS, A*, MCTS) to find a sequence of actions that transforms the current state into a goal state before executing.

## Strengths

Can solve complex multi-step problems; goals are explicit and interpretable; flexible since changing the goal re-plans without code changes.

## Limitations

Planning can be computationally expensive; requires an accurate model of action effects; may fail in highly dynamic environments where the plan becomes invalid mid-execution.

## Typical Examples

Route-planning navigation agents, chess-playing agents, robotic assembly planners, task scheduling assistants.
