## Definition

An agent with a secure code execution environment as a core capability, using code as the primary medium for computation and problem-solving.

## How It Works

Integrates a sandboxed code execution kernel (Python, R, JavaScript) alongside an LLM. The agent generates code to solve sub-problems, executes it, reads the output, and uses the result to generate further code or a final answer. All execution is isolated from the host.

## Strengths

Exact computation via code rather than approximate LLM arithmetic; reproducible; handles data manipulation, visualisation and mathematical tasks accurately.

## Limitations

Sandbox escape risks if isolation is imperfect; generated code can have bugs; slow for tasks where plain text would suffice; managing library dependencies in the sandbox is non-trivial.

## Typical Examples

ChatGPT Code Interpreter, Gemini Advanced code execution, Jupyter AI, enterprise data analysis agents.
