## Definition

Two or more agents interacting, collaborating or competing to solve problems beyond any single agent's capability.

## How It Works

Multiple agents, each with its own context, tools and potentially different models, communicate through a shared message bus, blackboard or direct messaging protocol. They may have symmetric roles (peers) or asymmetric roles (supervisor/worker). Coordination mechanisms prevent conflicts and deadlocks.

## Strengths

Parallel processing; specialisation; redundancy via multiple independent solvers; emergent problem-solving through agent interaction.

## Limitations

Coordination complexity; communication overhead; risk of conflicting actions; difficult to debug and observe; emergent behaviours can be unexpected.

## Typical Examples

AutoGen multi-agent conversations, Microsoft Semantic Kernel agent groups, A2A protocol-connected agent networks.
