## Definition

Executes tasks requiring many sequential steps over extended time periods, maintaining state and context across dozens to hundreds of actions.

## How It Works

Decomposes a high-level goal into a plan; executes steps iteratively using tools and memory; persists intermediate state to durable storage so work survives interruptions; monitors progress against the original plan and replans when blocked; requests human assistance only when genuinely stuck.

## Strengths

Handles complex multi-stage projects autonomously; reduces need for constant human supervision; can run overnight or over days.

## Limitations

Reliability degrades with horizon length as errors compound; long context management is challenging; difficult to test end-to-end; catastrophic failure modes when unrecoverable errors occur.

## Typical Examples

Devin software engineering agent, AutoGPT-style agents, overnight data pipeline agents, autonomous scientific experiment agents.
