## Definition

Reacts to current percept using condition-action rules with no memory of past states. The simplest agent architecture defined in classical AI literature.

## How It Works

Receives a percept from the environment; looks up a matching condition in a fixed set of if-then rules; executes the mapped action immediately. No internal state is maintained between cycles.

## Strengths

Extremely fast response with minimal compute; easy to implement, test and reason about; deterministic and auditable behaviour.

## Limitations

Cannot handle partially observable environments; ignores history so it loops in the same state; brittle when rules do not cover a situation.

## Typical Examples

Thermostat controllers, spam filters with keyword rules, simple IRC bots, early video-game NPCs.
