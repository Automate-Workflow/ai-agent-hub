## Definition

Receives spoken input via speech-to-text (STT), processes it with an LLM or dialogue manager, and responds with spoken output via text-to-speech (TTS).

## How It Works

Audio is captured and streamed to an STT engine which produces a transcript. The transcript is processed by an LLM-based dialogue manager (with optional tool calls). The response text is passed to a TTS engine and played back. Turn-taking logic handles interruptions and silence detection.

## Strengths

Hands-free interaction; accessible to non-typing users; natural for real-time customer service and IVR replacements.

## Limitations

STT errors propagate; latency compounds across STT+LLM+TTS pipeline; difficult to handle ambiguous or accented speech; privacy concerns with always-on microphones.

## Typical Examples

Amazon Alexa, Google Assistant, voice IVR systems, voice-controlled IoT devices, call-centre voice bots.
