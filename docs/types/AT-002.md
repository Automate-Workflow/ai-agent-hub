## Definition

Maintains an internal model of the world to handle partial observability while still using condition-action rules for decisions.

## How It Works

Updates an internal world-state representation each cycle by combining the current percept with the previous state and a transition model. Condition-action rules are then applied to this enriched state rather than the raw percept alone.

## Strengths

Handles partial observability; avoids repeating actions that have already changed hidden state; still fast enough for real-time use.

## Limitations

World model must be hand-crafted or learned and can go stale; complexity grows with environment size; still cannot pursue goals beyond the fixed rule set.

## Typical Examples

Autonomous vacuum robots maintaining a map of cleaned cells, early autonomous vehicle lane-keeping systems, rule-based fraud detection with rolling window state.
