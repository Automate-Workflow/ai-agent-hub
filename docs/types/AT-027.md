## Definition

Classifies incoming requests and directs them to the appropriate specialised agent or processing pipeline based on intent, topic or format.

## How It Works

Receives an input (user message, event, document); applies a classification model or LLM prompt to determine the intent and required handler; routes the input to the matching agent or pipeline with any necessary context; may also apply load balancing across multiple instances of the same handler.

## Strengths

Enables a system to handle heterogeneous inputs without monolithic logic; keeps specialist agents focused; easy to extend by adding new routes.

## Limitations

Misclassification sends requests to the wrong handler; routing logic must be kept in sync with available agents; adds a round-trip latency; can become a bottleneck.

## Typical Examples

Intent-based chatbot routers, API gateway agents, multi-domain customer service dispatchers, model selector agents.
