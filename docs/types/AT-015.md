## Definition

Writes and executes code or SQL to analyse datasets, generate visualisations and produce insights on demand from natural language questions.

## How It Works

Receives a data question or task; connects to datasets via file access or database connectors; generates pandas, SQL or R code to perform analysis; executes in a sandboxed interpreter; returns results, tables and charts; iterates if the output does not answer the question.

## Strengths

Democratises data analysis; reproducible; can handle datasets too large to fit in a prompt; produces visual outputs.

## Limitations

Requires access to data which may be sensitive; generated SQL or code can be incorrect; visualisation quality varies; hallucinations about numerical results are dangerous.

## Typical Examples

Code Interpreter in ChatGPT, Gemini Advanced data analysis, Julius AI, enterprise BI agents on warehouse data.
