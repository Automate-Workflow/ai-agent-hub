## Definition

Controls a web browser or full desktop to interact with websites and GUI applications as a human would, using visual understanding and UI automation.

## How It Works

Takes a goal; opens a browser or desktop session; uses vision models or accessibility trees to understand the current UI state; generates mouse, keyboard or touch actions; executes them via browser automation APIs (Playwright, Puppeteer) or OS-level injection; observes the result and continues until the goal is achieved.

## Strengths

Can automate any web or desktop workflow without an API; works with legacy software; handles dynamic UIs.

## Limitations

Fragile to UI changes; slow compared to API calls; difficult to handle CAPTCHAs and authentication flows; high error rate on complex multi-step tasks; raises security concerns.

## Typical Examples

Anthropic Computer Use, OpenAI Operator, browser-use library agents, RPA bots augmented with LLMs.
