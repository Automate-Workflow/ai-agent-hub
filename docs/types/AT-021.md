# AT-021: hierarchical_agent

## Definition

Structured as a tree of agents: a supervisor breaks goals into subtasks, delegates to specialists, aggregates results, and maintains quality oversight.

## How It Works

A top-level orchestrator receives the goal and produces a decomposed plan. Each subtask is dispatched to a specialist worker agent. Workers execute and return results. The orchestrator evaluates results, handles failures by re-delegating, and assembles the final output.

## Strengths

Scales to complex tasks; specialist agents can be tuned for their domain; isolates failures to subtask level; natural fit for parallel execution.

## Limitations

Communication overhead grows with depth; orchestrator is a single point of failure; requires careful interface design between layers; debugging cross-layer failures is complex.

## Typical Examples

LangGraph supervisor graphs, AutoGen group chat with manager, CrewAI hierarchical crews, enterprise agent pipelines.
