## Definition

An agent whose primary role is to judge the quality, correctness or safety of another agent's output and report a structured evaluation.

## How It Works

Receives an output from a producer agent along with the original task specification and an evaluation rubric. Applies the rubric to generate a structured critique with scores, identified issues and improvement suggestions. Sends the critique back to the orchestrator or directly to the producer.

## Strengths

Improves output quality through automated review; enables iterative refinement without human review of every output; can enforce style, accuracy and safety standards.

## Limitations

Critic quality depends on its own reasoning ability; critics can agree with errors they should catch; adds latency and cost to each generation cycle.

## Typical Examples

Self-refinement critics, LLM-as-judge evaluators, automated PR review agents, test-writing agents that verify code correctness.
