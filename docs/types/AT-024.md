## Definition

A focused agent that receives well-defined subtasks from an orchestrator and executes them without broad planning responsibility.

## How It Works

Receives a structured task description from an orchestrator; executes using its specialised tools and knowledge; returns a structured result; handles retries within its own scope; does not need visibility of the full goal.

## Strengths

Highly focused; can be optimised for a narrow task; independently testable; replaceable without affecting the orchestrator.

## Limitations

Dependent on the orchestrator for task framing; limited ability to self-direct when the task description is ambiguous; not useful in isolation.

## Typical Examples

Web search worker, code execution worker, document summariser worker, database query worker in multi-agent pipelines.
