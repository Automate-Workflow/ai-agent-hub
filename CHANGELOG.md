## [1.0.0] — 2026-11-11

### Added

- Initial knowledge base with 120+ concepts across 11 categories
- 35+ agent type definitions with three lenses (decision logic, job, architecture)
- 30+ agentic patterns with intent, structure, and tradeoffs
- 12+ verified protocols and standards (MCP, A2A, OpenAPI, JSON Schema, OAuth 2.x, OpenTelemetry)
- 50+ frameworks and tools with verified licenses and source URLs
- 70+ industry use cases across 18 sectors
- 40+ risks and security entries grounded in OWASP LLM Top 10 and NIST AI RMF
- 30+ evaluation metrics, methods, and benchmarks
- 100+ learning path steps across five structured paths (Foundations, Builder, Architect,
  Security and Governance, Team Lead)
- 150+ verified learning resources
- 150+ research sources with reliability ratings
- 600+ relationship edges connecting all entries across datasets
- 13 hand-written SVG diagrams: agent landscape, anatomy, reasoning loop, concept map,
  protocol stack, patterns overview, autonomy ladder, RAG pipeline, multi-agent topologies,
  risk heatmap, learning roadmap, decision tree, security layers
- Complete asset set: logo, banner, icons, badges, dividers
- Generated SVG charts from CSV data
- Interactive static explorer with search, filters, force-directed graph, and learning path tracker
- Full CI pipeline: data validation, link checking, site build, and GitHub Pages deployment
- Policy files: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, SUPPORT, GOVERNANCE
- Dual licensing: MIT for code, CC BY 4.0 for data and documentation
- CITATION.cff for academic citation support
- ROADMAP.md outlining goals through Q3 2027
